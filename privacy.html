Privacy Policy

Effective November 2, 2026. This policy covers Pause First Poster, the tool Pause First uses to publish its own videos.

Who uses the tool

Only the Pause First team uses Pause First Poster, and only with Pause First's own accounts. It does not offer sign-in to the public.

What it accesses

  • YouTube: permission to upload videos to the Pause First channel.
  • Facebook and Instagram: permission to publish to, and read basic information about, the Pause First Page and its linked Instagram account.
  • TikTok: permission to publish to the Pause First account.

It does not collect personal information about viewers or the public.

How the information is used and stored

Access tokens are used only to publish Pause First videos. They are stored encrypted as GitHub Actions secrets and are not sold or shared with anyone else. Platform post IDs and posting results are kept in a private log so we can tell what was published.

Google and YouTube

The tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Access can be revoked at any time from Google security settings.

Deleting data

To remove the tool's access, revoke it in the platform's settings and we delete the stored token. To ask about any data, or to request deletion, email the address below.

Changes

If this policy changes, we update this page and its effective date.
